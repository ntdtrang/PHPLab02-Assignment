# PHP-Lab02 – Workshop Booking Portal

Nguyễn Thị Diễm Trang – MSSV: 24110261

Ứng dụng PHP thuần, không database, booking lưu trong Session.

## Cách chạy
1. Copy folder vào `C:\xampp\htdocs\` (hoặc chạy `php -S localhost:8000` trong folder).
2. Mở http://localhost/php-s07-workshop/index.php

## Chức năng
- Catalog, tìm kiếm GET (q, category)
- Booking POST: validation, CSRF, Post/Redirect/Get
- Dashboard, Clear session, theme cookie
- booking_detail.php (View Details) và booking_edit.php (Edit)
